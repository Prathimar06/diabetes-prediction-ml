# Dataset

Place the downloaded file here as:

`data/diabetes.csv`

The CSV should have these columns:

`PatientID,Pregnancies,PlasmaGlucose,DiastolicBloodPressure,TricepsThickness,SerumInsulin,BMI,DiabetesPedigree,Age,Diabetic`

The source dataset is the same 10,000-row `diabetes.csv` used by the reference project.
After you save it here, the project does not download anything from another repository at runtime.
